## ⚙️ Configuration: Set up Gemini API

1. Open [backend/.env](file:///Users/orz/gram-prog/backend/.env) in your editor.
2. Locate the line:
   ```env
   GEMINI_API_KEY=
   ```
3. Paste your Google Gemini API key (obtained from [Google AI Studio](https://aistudio.google.com/)) after the `=`. For example:
   ```env
   GEMINI_API_KEY=AIzaSyA1...
   ```
4. Save the file.

> [!NOTE]
> The backend features a secure self-check. If no API key is specified, the application will boot successfully but will gracefully display an warning in the frontend badge ("API Key Missing") and prompt you with an action alert, rather than crashing.

## 🚀 Running the Application

To boot both the **Express backend server** (port 4000) and the **Vite React dev client** (port 5173) simultaneously:

1. Open your terminal in the root directory `/Users/orz/gram-prog`.
2. Execute the following single command:
   ```bash
   npm run dev
   ```
3. Once running, open your web browser to:
   👉 **[http://localhost:5173](http://localhost:5173)**

## 💡 Visual Features Showcase

### 1. Distraction-Free Paper Workspace
*   Styled like a premium physical notebook page using **Lora** (a gorgeous literary serif font) with generous line-heights.
*   Uses a synchronized layered backdrop rendering engine. Underlines are drawn underneath the text with zero caret distortion or typing latency.

### 2. Live Suggestion Sidebar
*   Corrective recommendations appear instantly as you type (auto-checking is debounced by 1.8s, or you can switch to manual trigger).
*   Color-coded highlights signify specific issue types:
    *   🔴 **Spelling**: Red underlines
    *   🔵 **Grammar**: Blue underlines
    *   🟡 **Clarity / Style**: Yellow underlines
    *   🟣 **Tone**: Purple underlines
*   Click **Accept** on any card to replace the word instantly. The remaining offsets in the document automatically shift positions.
*   Click **Accept All** to trigger a highly advanced three-step corrections pipeline:
    1. **Correction**: Detects and compiles all spelling & grammatical issues.
    2. **Minimal Edit**: Uses zero-temperature AI rewrite to correct all issues with the absolute minimum changes, strictly preserving your original tone, style, and content without any additions or deletions.
    3. **Re-validation & UI Present**: Automatically runs a secondary backend check on the polished text, presents the pristine, error-free result inside the editor, and safely disables **Auto-check** so your writing focus remains completely locked.

### 3. AI Tone Rewriter
*   Click **AI Rewriter** at the bottom of the canvas to open the overlay panel.
*   Select one of the 6 tone presets (Professional, Casual, Confident, Academic, Friendly, Concise) and click **Rewrite Document**.
*   A clean side-by-side diff appears, accompanied by a shift rationale log generated by Gemini, before letting you replace your document text in one click.

### 4. Real-time Analytics Pill
*   Sits elegantly at the bottom center of your editor.
*   Displays word count, character count, estimated reading duration, readability accessibility, and overall dominant emotional tone.
